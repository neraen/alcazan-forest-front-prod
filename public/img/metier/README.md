# Icônes des métiers

Convention : `/img/metier/<icone>.png`, où `<icone>` est le champ « Icône » de l'onglet
Métiers de l'ArtisanatMaker (**sans extension** — le jeu recolle `.png`).

Les images arrivent ici par l'upload de l'administration : le fichier est renommé d'après le
nom du métier (« Maître bûcheron » → `maitre-bucheron.png`). Rien à déposer à la main.
