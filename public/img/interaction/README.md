# Images des cases interactives

Convention : `/img/interaction/<skin>.png`, où `<skin>` est le champ « skin » saisi dans
l'InteractionMaker (sans extension).

Tant qu'aucune image n'est fournie, la case affiche un **repère par défaut** (anneau or
pulsant) : une case interactive doit toujours se voir, sinon le joueur ne peut pas la
trouver. Déposer une image ici la remplace automatiquement.
